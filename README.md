# 🌙 Sukoon — A Moment of Peace

Sukoon is a peaceful and interactive web application designed to provide users with a moment of reflection based on how they are feeling.

The user selects their current mood, and Sukoon provides a relevant Quranic reminder, a Dua, a thoughtful quote, and a small activity that they can try.

## ✨ Features

- 🌙 Calm and peaceful user interface
- 😊 Multiple mood options
- 📖 Quranic verses/reminders related to the selected mood
- 🤲 Dua section with relevant duas
- 💭 Thoughtful and motivational quotes
- 🌱 Small activities for the user
- 🔄 "Another Reminder" generates a different Quranic reminder, Dua, quote, and activity
- 📱 Responsive design for mobile and desktop
- 🎨 Peaceful Islamic-inspired color theme

## 🧠 How It Works

1. Open the Sukoon website.
2. Select how you are feeling.
3. Sukoon displays a relevant Quranic reminder.
4. Read the Quranic verse and its translation.
5. Read the related Dua.
6. Read the accompanying thought.
7. Try the suggested activity.
8. Click **Another Reminder** to receive new content.

## 🤲 Dua Section

Sukoon also includes a dedicated Dua section where users can find a relevant Dua according to their selected mood.

The Dua content changes along with the Quranic reminder so that users can receive a different spiritual reminder each time.
